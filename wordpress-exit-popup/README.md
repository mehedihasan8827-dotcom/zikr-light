# এক্সিট-ইনটেন্ট ডিসকাউন্ট পপআপ — ওয়ার্ডপ্রেস + Elementor

ল্যান্ডিং পেজ থেকে বেরিয়ে যেতে চাওয়া ভিজিটরদের তাৎক্ষণিক ডিসকাউন্ট (৳৫০/৳১০০)
অফার করে অর্ডারে রূপান্তর করার একটি কাস্টম সলিউশন। কোনো পেইড প্লাগইন লাগবে না।

## কেন এটি কাজ করবে

আপনার বর্তমান অবস্থা: দৈনিক ~১০০০ ভিজিটর, ৫০–৭০ অর্ডার (কনভার্শন ৫–৭%)।
অর্থাৎ দিনে ৯৩০+ ভিজিটর না কিনেই চলে যাচ্ছেন। এক্সিট-ইনটেন্ট পপআপ সাধারণত
বেরিয়ে যাওয়া ভিজিটরদের ২–৪% ফিরিয়ে আনে — সেই হিসাবে দিনে অতিরিক্ত
১৫–৩০টি অর্ডারের সম্ভাবনা তৈরি হয়।

## কীভাবে কাজ করে (ফ্লো)

1. ভিজিটর পেজে আসেন; স্ক্রিপ্ট **ট্যাব খোলা থাকা অবস্থার** সময় গণনা করে।
2. **৪৫ সেকেন্ড** পার হলে পপআপ "সক্রিয়" (armed) হয়।
3. এরপর ভিজিটর বেরিয়ে যাওয়ার চেষ্টা করলে পপআপ দেখা যায়:
   - **ডেস্কটপ:** মাউস কার্সার ব্রাউজারের উপরের দিকে (ট্যাব/ক্লোজ বাটনের দিকে) গেলে
   - **মোবাইল:** ব্যাক বাটন চাপলে, অথবা খুব দ্রুত উপরের দিকে স্ক্রল করলে
4. পপআপে ডিসকাউন্ট অফার + ১৫ মিনিটের কাউন্টডাউন টাইমার দেখানো হয়।
5. **"ডিসকাউন্ট নিয়ে অর্ডার করুন"** চাপলে:
   - একটি কুকি সেট হয় এবং ভিজিটর চেকআউটে যান (`?exit_coupon=EXIT100` সহ)
   - PHP স্নিপেট কুপনটি **অটোমেটিক কার্টে অ্যাপ্লাই** করে — মূল দাম থেকে টাকা কেটে যায়
6. অর্ডার শেষে কাস্টমার WooCommerce-এর **থ্যাংক ইউ পেজে** (order-received) চলে যান।
7. একই ভিজিটরকে ২৪ ঘণ্টার মধ্যে আবার পপআপ দেখানো হয় না; ডিসকাউন্ট নেওয়া
   থাকলেও আর দেখানো হয় না।

## ফাইলসমূহ

| ফাইল | কোথায় বসাবেন |
|---|---|
| `exit-intent-popup.html` | Elementor পেজে একটি **HTML উইজেট**-এ (CSS + HTML + JS একসাথে) |
| `woocommerce-coupon.php` | **WPCode** / **Code Snippets** প্লাগইনে PHP স্নিপেট হিসেবে, অথবা চাইল্ড থিমের `functions.php`-তে |

## ইন্সটলেশন (ধাপে ধাপে)

### ধাপ ১: WooCommerce কুপন তৈরি করুন

1. WP অ্যাডমিন → **Marketing → Coupons → Add coupon**
2. কুপন কোড: `EXIT100` (৫০ টাকার অফার চাইলে `EXIT50`)
3. **Discount type:** Fixed cart discount, **Amount:** `100`
4. **Usage limits → Usage limit per user:** `1` (একজন কাস্টমার একবারই পাবেন)
5. চাইলে **Minimum spend** দিন, যেন ছোট অর্ডারে ডিসকাউন্ট না যায়।

### ধাপ ২: PHP স্নিপেট যোগ করুন

1. **WPCode** (ফ্রি) প্লাগইন ইন্সটল করুন → Code Snippets → Add New → PHP Snippet
2. `woocommerce-coupon.php`-এর কোড পেস্ট করুন (শুরুর `<?php` বাদ দিয়ে) → Activate

### ধাপ ৩: পপআপ যোগ করুন

1. Elementor-এ ল্যান্ডিং পেজটি এডিট করুন
2. পেজের একদম নিচে একটি **HTML উইজেট** টেনে আনুন
3. `exit-intent-popup.html`-এর পুরো কোড পেস্ট করুন
4. `CONFIG` অংশে নিজের মান বসান — বিশেষ করে:
   - `discountAmount: 100` এবং `couponCode: 'EXIT100'` (কুপনের সাথে মিল রাখুন)
   - `ctaUrl: '/checkout/?add-to-cart=123'` — `123`-এর জায়গায় আপনার
     প্রোডাক্টের ID দিন (Products তালিকায় প্রোডাক্টের উপর হোভার করলে ID দেখা যায়)

### ধাপ ৪: টেস্ট করুন

- [ ] পেজ খুলে ৪৫ সেকেন্ড অপেক্ষা করে মাউস ব্রাউজারের উপরের দিকে নিন → পপআপ আসবে
- [ ] ৪৫ সেকেন্ডের **আগে** মাউস উপরে নিলে পপআপ আসবে **না**
- [ ] মোবাইলে ৪৫ সেকেন্ড পরে ব্যাক বাটন চাপুন → পপআপ আসবে
- [ ] CTA চাপলে চেকআউটে ডিসকাউন্ট কাটা অবস্থায় দাম দেখা যাবে
- [ ] টেস্ট অর্ডার শেষ করলে থ্যাংক ইউ পেজ আসবে
- [ ] পেজ রিফ্রেশ করলে পপআপ আবার আসবে না (২৪ ঘণ্টার ক্যাপ)
- [ ] আবার টেস্টের জন্য: ব্রাউজার DevTools → Application → Local Storage থেকে
      `zl_exit_shown_at` ও `zl_exit_deadline` মুছুন এবং `zl_exit_coupon` কুকি মুছুন

## কনফিগারেশন রেফারেন্স

`exit-intent-popup.html`-এর `CONFIG` অবজেক্ট:

| সেটিং | ডিফল্ট | ব্যাখ্যা |
|---|---|---|
| `minSecondsOnPage` | `45` | পপআপ সক্রিয় হওয়ার আগে ন্যূনতম সময় (সেকেন্ড) |
| `discountAmount` | `100` | পপআপে দেখানো ডিসকাউন্ট (টাকা) |
| `couponCode` | `'EXIT100'` | WooCommerce কুপন কোড |
| `offerMinutes` | `15` | কাউন্টডাউন টাইমার — সময় শেষে পপআপ বন্ধ হয় |
| `frequencyHours` | `24` | একই ভিজিটরকে আবার দেখানোর ব্যবধান |
| `mode` | `'woocommerce'` | `'woocommerce'` = চেকআউটে রিডাইরেক্ট; `'form'` = একই পেজের অর্ডার ফর্ম |
| `ctaUrl` | `/checkout/?add-to-cart=123` | woocommerce মোডে CTA-র গন্তব্য |

### `form` মোড (WooCommerce ছাড়া, ল্যান্ডিং পেজের নিজস্ব অর্ডার ফর্ম)

অনেক ল্যান্ডিং পেজে কার্ট থাকে না — পেজের নিচেই অর্ডার ফর্ম থাকে (ক্যাশ অন
ডেলিভারি)। সেক্ষেত্রে `mode: 'form'` দিন:

- দাম দেখানোর জায়গায় লিখুন: `<span data-zl-price="990">৳৯৯০</span>` —
  ডিসকাউন্ট নিলে এটি স্বয়ংক্রিয়ভাবে <del>৳৯৯০</del> **৳৮৯০** হয়ে যাবে
- Elementor ফর্মে একটি **hidden field** যোগ করুন যার name `zl_discount` —
  ডিসকাউন্ট নেওয়া হলে এতে `EXIT100:100` মান বসবে, ফলে অর্ডার নোটিফিকেশনে
  আপনি দেখবেন কে ডিসকাউন্ট পেয়েছে
- ফর্ম সাবমিটের পর Elementor ফর্মের **Actions After Submit → Redirect**
  দিয়ে আপনার থ্যাংক ইউ পেজে পাঠান

## গুরুত্বপূর্ণ সতর্কতা

- **ক্যাশ প্লাগইন:** পপআপ পুরোটাই ব্রাউজারে (JavaScript) চলে, তাই WP Rocket /
  LiteSpeed ক্যাশে সমস্যা হবে না। তবে "Delay JavaScript execution" চালু থাকলে
  এই স্ক্রিপ্টকে exclude করুন, নইলে ৪৫ সেকেন্ডের হিসাব দেরিতে শুরু হতে পারে।
- **নিরাপত্তা:** PHP স্নিপেটে কুপনের whitelist আছে (`EXIT50`, `EXIT100`) —
  URL-এ অন্য কোনো কুপন কোড দিলে তা অ্যাপ্লাই হবে না। কুপনের usage limit
  অপব্যবহার ঠেকায়।
- **ট্র্যাকিং:** পপআপ দেখা গেলে `exit_popup_shown` এবং CTA চাপলে
  `exit_popup_claimed` নামে dataLayer ইভেন্ট পাঠানো হয় — GTM/GA4/Meta Pixel-এ
  কাস্টম ইভেন্ট হিসেবে ব্যবহার করে পপআপের কনভার্শন মাপতে পারবেন।
- **A/B টেস্ট:** প্রথম সপ্তাহে ৳৫০ আর পরের সপ্তাহে ৳১০০ চালিয়ে দেখুন কোনটিতে
  লাভ (ডিসকাউন্ট খরচ বাদ দিয়ে) বেশি থাকে।
