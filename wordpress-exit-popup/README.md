# এক্সিট-ইনটেন্ট ডিসকাউন্ট পপআপ — WordPress + Elementor + WooCommerce + CartFlows Pro

ল্যান্ডিং পেজ থেকে বেরিয়ে যেতে চাওয়া ভিজিটরদের তাৎক্ষণিক ডিসকাউন্ট (৳৫০/৳১০০)
অফার করে অর্ডারে রূপান্তর করার একটি কাস্টম সলিউশন। আলাদা কার্ট পেজ ছাড়া,
পেজের নিচে এমবেড করা অর্ডার ফর্মের (CartFlows চেকআউট) জন্য তৈরি।
কোনো পেইড পপআপ প্লাগইন লাগবে না।

## কেন এটি কাজ করবে

আপনার বর্তমান অবস্থা: দৈনিক ~১০০০ ভিজিটর, ৫০–৭০ অর্ডার (কনভার্শন ৫–৭%)।
অর্থাৎ দিনে ৯৩০+ ভিজিটর না কিনেই চলে যাচ্ছেন। এক্সিট-ইনটেন্ট পপআপ সাধারণত
বেরিয়ে যাওয়া ভিজিটরদের ২–৪% ফিরিয়ে আনে — সেই হিসাবে দিনে অতিরিক্ত
১৫–৩০টি অর্ডারের সম্ভাবনা তৈরি হয়।

## কীভাবে কাজ করে (সম্পূর্ণ ফ্লো)

1. ভিজিটর পেজে আসেন; স্ক্রিপ্ট **ট্যাব খোলা থাকা অবস্থার** সময় গণনা করে
   (ট্যাব মিনিমাইজ থাকলে সময় গোনা হয় না)।
2. **৪৫ সেকেন্ড** পার হলে পপআপ "সক্রিয়" (armed) হয় — এর আগে কোনো
   অবস্থাতেই পপআপ আসবে না।
3. এরপর ভিজিটর বেরিয়ে যাওয়ার চেষ্টা করলে পপআপ দেখা যায়:
   - **ডেস্কটপ:** মাউস কার্সার ব্রাউজারের উপরের দিকে (ট্যাব/ক্লোজ বাটনের দিকে) গেলে
   - **মোবাইল:** ব্যাক বাটন চাপলে, অথবা খুব দ্রুত উপরের দিকে স্ক্রল করলে
4. পপআপে ডিসকাউন্ট অফার + ১৫ মিনিটের কাউন্টডাউন টাইমার দেখানো হয়
   (`exit_popup_shown` ইভেন্ট dataLayer-এ যায়)।
5. **"ডিসকাউন্ট নিয়ে অর্ডার করুন"** চাপলে (`exit_popup_claimed` ইভেন্ট):
   - JavaScript **AJAX কলের মাধ্যমে কুপনটি WooCommerce কার্টে অটো-অ্যাপ্লাই**
     করে — পেজ রিলোড হয় না, ভিজিটর পেজেই থাকেন
   - CartFlows-এর অর্ডার ফর্মের টোটাল রিফ্রেশ হয় (`update_checkout`) —
     **মূল দাম থেকে ডিসকাউন্ট কাটা অবস্থায়** অর্ডার সামারিতে দেখা যায়
   - ফর্মের উপরে সবুজ নিশ্চিতকরণ বার্তা বসে এবং পেজ স্মুথলি
     অর্ডার ফর্মে স্ক্রল করে
   - ফলব্যাক হিসেবে একটি কুকিও সেট হয় — AJAX কোনো কারণে ব্যর্থ হলে
     পরের পেজলোডে PHP স্নিপেট কুপনটি অ্যাপ্লাই করে দেয়
6. ভিজিটর ফর্ম পূরণ করে অর্ডার দিলে CartFlows স্বাভাবিকভাবেই তার
   **থ্যাংক ইউ স্টেপে** পাঠায়; কুকি-সেশন মুছে যায়।
7. একই ভিজিটরকে ২৪ ঘণ্টার মধ্যে আবার পপআপ দেখানো হয় না; ডিসকাউন্ট
   নেওয়া থাকলেও আর দেখানো হয় না।

|---|---|

## ইন্সটলেশন (ধাপে ধাপে)

### ধাপ ১: WooCommerce কুপন তৈরি করুন

1. WP অ্যাডমিন → **Marketing → Coupons → Add coupon**
2. কুপন কোড: `EXIT100` (৫০ টাকার অফার চাইলে `EXIT50`)
3. **Discount type:** Fixed cart discount, **Amount:** `100`
4. **Usage limits → Usage limit per user:** `1` (একজন কাস্টমার একবারই পাবেন)
5. চাইলে **Minimum spend** দিন, যেন ছোট অর্ডারে ডিসকাউন্ট না যায়।

> **CartFlows নোট:** CartFlows চেকআউট স্টেপের সেটিংসে যদি
> "Auto apply coupon" ফিল্ড ব্যবহার করে থাকেন, সেখানে **এই কুপনটি দেবেন
> না** — এটি শুধু পপআপ থেকে অ্যাপ্লাই হবে। CartFlows-এ কুপন ফিল্ড
> লুকানো থাকলেও সমস্যা নেই, কুপন সার্ভার-সাইডে অ্যাপ্লাই হয়।

### ধাপ ২: PHP স্নিপেট যোগ করুন

1. **WPCode** (ফ্রি) প্লাগইন ইন্সটল করুন → Code Snippets → Add New → PHP Snippet
2. `woocommerce-coupon.php`-এর কোড পেস্ট করুন (শুরুর `<?php` বাদ দিয়ে) → Activate

### ধাপ ৩: পপআপ যোগ করুন

1. Elementor-এ ল্যান্ডিং পেজটি এডিট করুন
2. পেজের একদম নিচে একটি **HTML উইজেট** টেনে আনুন
3. `exit-intent-popup.html`-এর পুরো কোড পেস্ট করুন
4. `CONFIG` অংশে নিজের মান বসান:
   - `discountAmount: 100` এবং `couponCode: 'EXIT100'` (ধাপ ১-এর কুপনের সাথে হুবহু মিল রাখুন)
   - `mode: 'form'` — আগে থেকেই সেট করা আছে (পেজে এমবেড করা অর্ডার ফর্মের জন্য)
   - `orderFormSelector` — ডিফল্টেই CartFlows/WooCommerce চেকআউট ফর্ম
     খুঁজে নেয়; নিজের কোনো সেকশনে স্ক্রল করাতে চাইলে Elementor-এ সেই
     সেকশনের CSS ID দিয়ে এখানে `'#order-form'` লিখুন

### ধাপ ৪ (ঐচ্ছিক): পেজের দামেও ডিসকাউন্ট দেখান

অর্ডার সামারির বাইরে পেজের অন্য জায়গায় (হেডলাইন, প্রাইস সেকশন) দাম
দেখালে সেখানে এই ফরম্যাট ব্যবহার করুন:

```html
<span data-zl-price="990">৳৯৯০</span>
```

ডিসকাউন্ট নেওয়ামাত্র এটি স্বয়ংক্রিয়ভাবে <del>৳৯৯০</del> **৳৮৯০** হয়ে যাবে।

## GTM / GA4 ট্র্যাকিং

পপআপের প্রতিটি ধাপে dataLayer ইভেন্ট পাঠানো হয়। প্রতিটি ইভেন্টের সাথে
`coupon_code`, `discount_amount`, `currency: 'BDT'` প্যারামিটার যায়:

| ইভেন্ট | কখন যায় | অতিরিক্ত প্যারামিটার |
|---|---|---|
| `exit_popup_shown` | পপআপ দেখা গেলে | `popup_trigger`: `mouse_exit` / `back_button` / `fast_scroll_up` |
| `exit_popup_claimed` | "ডিসকাউন্ট নিয়ে অর্ডার করুন" চাপলে | — |
| `exit_popup_coupon_applied` | AJAX-এ কুপন অ্যাপ্লাইয়ের ফল এলে | `apply_status`: `applied` / `already_applied` / `pending_empty_cart` / `ajax_error` ইত্যাদি |
| `exit_popup_dismissed` | ডিসকাউন্ট না নিয়ে বন্ধ করলে | `dismiss_method`: `close_button` / `no_thanks` / `overlay_click` / `escape_key` / `expired` |

### GTM-এ সেটআপ (একবারই করতে হবে)

1. **Variables:** তিনটি Data Layer Variable তৈরি করুন —
   `coupon_code`, `discount_amount`, `popup_trigger`
2. **Trigger:** Custom Event ট্রিগার তৈরি করুন, Event name-এ regex চালু করে:
   `exit_popup_shown|exit_popup_claimed|exit_popup_coupon_applied|exit_popup_dismissed`
3. **Tag:** একটি **GA4 Event** ট্যাগ তৈরি করুন —
   Event Name: `{{Event}}` (বিল্ট-ইন ভেরিয়েবল), Event Parameters-এ
   উপরের ভেরিয়েবলগুলো যুক্ত করুন, Trigger-এ ধাপ ২-এর ট্রিগার দিন
4. **GA4-এ:** Admin → Events-এ `exit_popup_claimed`-কে **Key event
   (conversion)** হিসেবে মার্ক করুন
5. Preview মোডে টেস্ট করে Publish করুন

এরপর GA4-এ দেখতে পাবেন: পপআপ কতবার দেখা গেছে, কতজন ডিসকাউন্ট নিয়েছেন
(ক্লেইম রেট), কোন ট্রিগারে (মোবাইল ব্যাক বাটন নাকি ডেস্কটপ মাউস) বেশি কাজ
হচ্ছে, আর purchase ইভেন্টের সাথে মিলিয়ে পপআপ থেকে আসা প্রকৃত অর্ডার সংখ্যা।

## কনফিগারেশন রেফারেন্স

`exit-intent-popup.html`-এর `CONFIG` অবজেক্ট:

| সেটিং | ডিফল্ট | ব্যাখ্যা |
|---|---|---|
| `minSecondsOnPage` | `45` | পপআপ সক্রিয় হওয়ার আগে ন্যূনতম সময় (সেকেন্ড) |
| `discountAmount` | `100` | পপআপে দেখানো ডিসকাউন্ট (টাকা) |
| `couponCode` | `'EXIT100'` | WooCommerce কুপন কোড |
| `offerMinutes` | `15` | কাউন্টডাউন টাইমার — সময় শেষে পপআপ বন্ধ হয় |
| `frequencyHours` | `24` | একই ভিজিটরকে আবার দেখানোর ব্যবধান |
| `mode` | `'form'` | `'form'` = পেজেই AJAX-এ কুপন অ্যাপ্লাই (CartFlows); `'woocommerce'` = আলাদা চেকআউটে রিডাইরেক্ট |
| `ajaxUrl` | `/wp-admin/admin-ajax.php` | ওয়ার্ডপ্রেসের AJAX এন্ডপয়েন্ট — সাধারণত বদলাতে হয় না |
| `orderFormSelector` | CartFlows/Woo চেকআউট | ডিসকাউন্ট নেওয়ার পর কোথায় স্ক্রল করবে |
| `priceSelector` | `[data-zl-price]` | পেজে দাম দেখানোর এলিমেন্ট (ঐচ্ছিক) |

## গুরুত্বপূর্ণ সতর্কতা

- **ক্যাশ প্লাগইন:** পপআপ পুরোটাই ব্রাউজারে (JavaScript) চলে, তাই WP Rocket /
  LiteSpeed ক্যাশে সমস্যা হবে না। তবে "Delay JavaScript execution" চালু থাকলে
  এই স্ক্রিপ্টকে exclude করুন, নইলে ৪৫ সেকেন্ডের হিসাব দেরিতে শুরু হতে পারে।
  `admin-ajax.php` কখনোই ক্যাশ হয় না, তাই কুপন অ্যাপ্লাইয়ে সমস্যা নেই।
- **নিরাপত্তা:** PHP স্নিপেটে কুপনের whitelist আছে (`EXIT50`, `EXIT100`) —
  AJAX/URL-এ অন্য কোনো কুপন কোড পাঠালে তা অ্যাপ্লাই হবে না। কুপনের
  usage limit per user বারবার ডিসকাউন্ট নেওয়া ঠেকায়।
