# পপআপের স্বয়ংক্রিয় ব্রাউজার টেস্ট

প্লাগইনের আসল `exit-popup.js`/`exit-popup.css` ফাইলের উপর বাস্তব Chromium-এ
১৬টি টেস্ট চালায় (Playwright)। প্লাগইনের কোডে যেকোনো পরিবর্তনের পর এটি
চালিয়ে নিশ্চিত হোন কিছু ভাঙেনি:

```bash
cd tests
npm install playwright
node test.cjs   # প্রত্যাশিত: ১৬/১৬ পাস
```

টেস্টে যা যাচাই হয়: সময়ের গেট, ডেস্কটপ মাউস-এক্সিট, মোবাইল ব্যাক-বাটন
(পেজে থাকা + সময়ের আগে pass-through), দ্রুত স্ক্রল-আপ, কুপন AJAX + কুকি,
দাম আপডেট, সবুজ বার্তা, ফ্রিকোয়েন্সি ক্যাপ (দমন + সময় পেরোলে পুনরায়
দেখানো), GA4 dataLayer ইভেন্ট, বাংলা ডিজিটের কাউন্টডাউন।

নোট: `index.html` হলো ল্যান্ডিং পেজের নকল — এতে প্লাগইনের `wp_footer`
মার্কআপের কপি আছে এবং `zlExitCfg`-এ `minSecondsOnPage: 2` দেওয়া (টেস্ট
দ্রুত চালানোর জন্য; লজিক প্যারামেট্রিক, তাই ৪৫ সেকেন্ডের আচরণও একই)।
AJAX মক করা — WordPress সার্ভার লাগে না।
