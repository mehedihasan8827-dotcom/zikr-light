## ১. এক লাইনে প্রোডাক্ট

> **"আপনার কর্মদিবস সাজান সালাতের চারপাশে — সালাত সাজাবেন না কাজের ফাঁকে।"**

সালাত ফোকাস একটি PWA (installable web app) যা নামাজের সময়সূচী + ডিপ-ওয়ার্ক ফোকাস টাইমারকে একত্র করে। ফোকাস সেশন **স্বয়ংক্রিয়ভাবে নামাজের ওয়াক্ত অনুযায়ী ভাগ হয়** — ওয়াক্ত হলে app বলে: **"কাজ থামান, সালাতের সময় হয়েছে।"**

---

## ২. সমস্যা (Problem Statement)

### ২.১ মূল সমস্যা
দ্বীনদার উদ্যোক্তা ও পেশাজীবীদের দুটি বিপরীতমুখী টান:

1. **কাজের গভীরে ডুবে গেলে** নামাজ কাযা/দেরি হয়ে যায় — এবং এর জন্য অপরাধবোধ (guilt) হয়, যা কোনো সাধারণ prayer app সমাধান করে না।
2. **নামাজের কথা মাথায় রাখতে গেলে** কাজে পূর্ণ মনোযোগ (deep work) দেওয়া যায় না — "আর কতক্ষণ আছে?" বারবার চেক করতে হয়।

### ২.২ বিদ্যমান সমাধান কেন যথেষ্ট নয়

| সমাধান | ঘাটতি |
|---|---|
| Muslim Pro, Athan ইত্যাদি | শুধু আযানের notification দেয়; কাজের flow-এর সাথে কোনো সংযোগ নেই। Notification মিস হলেই শেষ। |
| Pomodoro / Forest / Focus apps | সালাত সম্পর্কে কিছুই জানে না; ২৫ মিনিটের সেশন আসরের ওয়াক্তের মাঝখানে পড়তে পারে। |
| ফোনের নিজস্ব রিমাইন্ডার | প্রতিদিন সময় বদলায়, ম্যানুয়ালি সেট করা অসম্ভব। |

**গ্যাপ:** নামাজের সময় ও কাজের সেশন — এই দুটোকে একসাথে ভাবা কোনো প্রোডাক্ট বাজারে নেই। এটাই আমাদের সুযোগ।

## ৩. টার্গেট ইউজার (Personas)

### Persona ১: "উদ্যোক্তা ভাই" — প্রাইমারি
- বয়স ২২–৪০, F-commerce/এজেন্সি/দোকান চালান, ফোনই তার অফিস
- ব্যথা: কাস্টমার মেসেজের চাপে আসর-মাগরিব প্রায়ই কাযা হয়
- চাওয়া: "কেউ আমাকে জোর করে থামাক"

### Persona ২: "রিমোট প্রফেশনাল" — সেকেন্ডারি
- ডেভেলপার/ডিজাইনার/ফ্রিল্যান্সার, ল্যাপটপে ৮–১০ ঘণ্টা
- ব্যথা: মিটিং ও ডেডলাইনের ভিড়ে যোহর পিছাতে পিছাতে আসরের কাছে চলে যায়
- চাওয়া: ক্যালেন্ডারের মতো করে দিনটা সালাত-কেন্দ্রিক ব্লকে ভাগ হোক

### Persona ৩: "ছাত্র/পড়ুয়া" — টারশিয়ারি
- পরীক্ষার প্রস্তুতি/পড়াশোনায় লম্বা সেশন
- চাওয়া: পড়ার streak + নামাজের streak একসাথে

## ৪. প্রোডাক্ট ভিশন ও ইউনিক ভ্যালু

### ৪.১ মূল ইনসাইট (Master Insight)
সাধারণ productivity app বলে: *"সময়কে কাজে লাগাও।"*
আমরা বলি: **"সময়ের মালিকানা আল্লাহর; সালাতের ওয়াক্তগুলোই তোমার দিনের প্রকৃত ক্যালেন্ডার।"**

দিনটা তাই আমাদের কাছে ২৪ ঘণ্টা নয় — **৫টা ওয়াক্তের মাঝের ৫–৬টা "ব্লক":**

```
ফজর ──[ব্লক ১: সকালের ডিপ ওয়ার্ক]── যোহর ──[ব্লক ২]── আসর ──[ব্লক ৩]── মাগরিব ──[ব্লক ৪]── এশা ──[ব্লক ৫: রাত]
```

এই "সালাত-ব্লক" ধারণাটাই প্রোডাক্টের প্রাণ ও ব্র্যান্ডিং হুক।

### ৪.২ ভ্যালু প্রপোজিশন
- **দ্বীনি দিক:** নামাজ আর কখনো কাজের চাপে হারাবে না
- **দুনিয়াবি দিক:** সালাত-ব্লক আসলে বিজ্ঞানসম্মত ultradian work cycle (৯০–১৮০ মিনিট) — অর্থাৎ নামাজ মানাই productivity-র জন্য পারফেক্ট বিরতি
- **আবেগীয় দিক:** guilt নয়, তৃপ্তি — "আজ ৫/৫ ওয়াক্ত সময়মতো + ৬ ঘণ্টা ডিপ ওয়ার্ক"

| মেট্রিক | টার্গেট (লঞ্চের ৯০ দিনে) |

## ৬. ফিচার স্পেসিফিকেশন

### P0 — MVP (এগুলো ছাড়া লঞ্চ নয়)

#### F1. নামাজের সময়সূচী (অফলাইন-ফার্স্ট)
- লোকেশন থেকে (GPS permission বা ম্যানুয়াল শহর নির্বাচন) ৫ ওয়াক্তের সময় **ডিভাইসেই গণনা** (adhan-js লাইব্রেরি) — কোনো সার্ভার/API লাগবে না, ফলে অফলাইনেও চলবে
- Calculation method নির্বাচনযোগ্য; **ডিফল্ট: Karachi method + Hanafi আসর** (বাংলাদেশের প্রেক্ষাপট)
- আজকের টাইমলাইন ভিউ: এখন কোন ব্লকে আছি, পরের ওয়াক্ত কতক্ষণ পরে

#### F2. সালাত-সচেতন ফোকাস টাইমার (হিরো ফিচার)
- User একটা কাজের নাম লিখে "ফোকাস শুরু" চাপবে
- টাইমার দেখাবে: elapsed time + **"পরের ওয়াক্ত (আসর) পর্যন্ত আর ১ঘ ২০মি"**
- সেশনের দৈর্ঘ্য স্বয়ংক্রিয়ভাবে ওয়াক্তে গিয়ে শেষ হয়; user চাইলে ছোট সেশনও (২৫/৫০ মি) নিতে পারবে, কিন্তু **কোনো সেশনই ওয়াক্ত পার হবে না**
- ওয়াক্তের X মিনিট আগে (configurable, ডিফল্ট ১৫ মি) সফট-warning: "গুছিয়ে আনুন, আসর আসছে"

#### F3. সালাত গেট (Salat Gate) — full-screen প্রম্পট
- ওয়াক্ত হলে টাইমার থেমে যায়, শান্ত-সুন্দর full-screen পর্দা:
  - "আসরের সময় হয়েছে" + সংশ্লিষ্ট একটি আয়াত/হাদিস
  - দুটি বাটন: **[সালাতে যাচ্ছি ✓]** / [৫ মিনিট পরে]
  - "৫ মিনিট পরে" সর্বোচ্চ ২ বার — এরপর শুধু "সালাতে যাচ্ছি"-ই থাকবে (nudge, জবরদস্তি নয়)
- ফিরে এসে "সালাত পড়েছি" মার্ক করলে পরের ব্লক শুরু করার অফার

#### F4. দৈনিক স্কোরবোর্ড ও Streak
- আজ: কয় ওয়াক্ত সময়মতো + মোট ফোকাস মিনিট
- Streak: টানা কত দিন ৫/৫ ওয়াক্ত (zikr-light-এর streak কোড reuse)
- সব ডেটা localStorage/IndexedDB-তে — **কোনো অ্যাকাউন্ট, কোনো সার্ভার নয়** (privacy সেলিং পয়েন্ট)

#### F5. PWA + Notifications
- Home screen-এ installable, সম্পূর্ণ অফলাইন-সক্ষম (zikr-light-এর PWA setup reuse)
- Web Notification: ওয়াক্ত শুরু + প্রি-ওয়ার্নিং
- Haptic feedback (সেশন শুরু/শেষ) — zikr-light থেকে reuse

### P1 — লঞ্চের পরপরই

- **সাপ্তাহিক রিপোর্ট কার্ড** (share-able image): "এই সপ্তাহে: ৩৩/৩৫ ওয়াক্ত সময়মতো, ২২ ঘণ্টা ডিপ ওয়ার্ক" — viral loop
- ব্লক-ভিত্তিক দিন-পরিকল্পনা: সকালেই প্রতিটি সালাত-ব্লকে ১টা করে কাজ assign
- আযান/নোটিফিকেশন সাউন্ড অপশন
- বাংলা + English ভাষা টগল

### P2 — ভবিষ্যৎ

- জামাতের সময় অফসেট (মসজিদে জামাত ওয়াক্তের X মিনিট পরে)
- সকাল-সন্ধ্যার যিকির integration (zikr-light-এর সাথে সেতু)
- Optional cloud sync + ডিভাইস-পারাপার
- টিম/অ্যাকাউন্টাবিলিটি সার্কেল: বন্ধুদের সাথে streak শেয়ার

### Out of Scope (সচেতনভাবে বাদ)

- ❌ ফোনের DND/app-blocking — web প্ল্যাটফর্মে সম্ভব নয়; আমরা "গেট + অভ্যাস" পদ্ধতিতে যাব, জোর-জবরদস্তিতে নয়
- ❌ কুরআন রিডার, কিবলা কম্পাস — অন্য app-এর কাজ; ফোকাস হারানো যাবে না
- ❌ সোশ্যাল ফিড/কমেন্ট — distraction app বানানো আমাদের লক্ষ্যবিরোধী

## ৭. মূল ইউজার ফ্লো

### ফ্লো ১: প্রথমবার ব্যবহার (Onboarding — সর্বোচ্চ ৩ স্ক্রিন)
1. স্বাগতম + ভ্যালু prop এক লাইনে
2. লোকেশন দিন (GPS বা শহর বাছাই) → সময়সূচী তৈরি
3. Notification permission চাওয়া (কারণসহ) → আজকের টাইমলাইনে ল্যান্ড

### ফ্লো ২: একটি ফোকাস সেশন
1. হোমে দেখে: "এখন যোহর-ব্লক, আসর পর্যন্ত ২ঘ ১০মি"
2. কাজের নাম লিখে ▶ শুরু
3. ১৫ মিনিট আগে সফট-ওয়ার্নিং → ওয়াক্তে **সালাত গেট**
4. [সালাতে যাচ্ছি] → ফিরে এসে "পড়েছি ✓" → স্কোর আপডেট → পরের ব্লক শুরু

### ফ্লো ৩: দিন শেষে
- এশার পরে দৈনিক সামারি: ওয়াক্ত স্কোর + ফোকাস মিনিট + streak — এক ট্যাপে কালকের পরিকল্পনা

## ৮. টেকনিক্যাল আর্কিটেকচার

| স্তর | সিদ্ধান্ত | কারণ |
|---|---|---|
| ফ্রেমওয়ার্ক | React + TypeScript + Vite + Tailwind + shadcn/ui | zikr-light-এর স্ট্যাক — কোড ও অভিজ্ঞতা reuse |
| নামাজ গণনা | `adhan` (npm) — client-side astronomical calculation | অফলাইন, ফ্রি, নির্ভুল, API dependency নেই |
| স্টোরেজ | localStorage (settings) + IndexedDB (session history) | সার্ভারবিহীন, প্রাইভেসি-ফার্স্ট |
| PWA | vite-plugin-pwa + service worker | zikr-light থেকে reuse |
| Notification | Web Notifications API + service worker scheduling | — |
| ব্যাকএন্ড | **নেই** (MVP) | দ্রুত শিপ, শূন্য খরচ, শূন্য ডেটা-ঝুঁকি |
| টেস্ট | Vitest | বিদ্যমান setup |

**জানা সীমাবদ্ধতা:** iOS Safari-তে PWA notification সীমিত (iOS 16.4+ এ install করা PWA-তে কাজ করে); app খোলা থাকলে in-app গেট সবসময় কাজ করবে — এটাই প্রাইমারি মেকানিজম, notification সেকেন্ডারি।

## ৯. মনিটাইজেশন (পরে, কিন্তু পথ পরিষ্কার)

- MVP: সম্পূর্ণ ফ্রি (গ্রোথ ফেজ)
